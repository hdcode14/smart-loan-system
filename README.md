# Smart Loan Management System

A comprehensive loan management platform built with Flask that automates the complete loan lifecycle.

## Features

- **User Authentication**: Secure login and registration
- **Loan Application**: Dynamic form with eligibility verification
- **Financial Health Scoring**: AI-based credit assessment
- **Wallet System**: Integrated digital wallet for repayments
- **Admin Dashboard**: Complete loan management for administrators
- **Real-time Tracking**: Live loan status and repayment tracking
